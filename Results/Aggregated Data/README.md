# Aggregated data

The primary catalog and outcomes contain 72 selected, audited profiles, including full precision welfare and participation measures. The main cost diagram covers all 20 American/British baseline profiles. Main-welfare-decomposition covers the ten baseline fee-rule comparisons. Trial-only fee shifting is restricted to cost 1.

Two pending risk-averse grid profiles are explicitly listed in the selected catalog. Approximate multiple-start results are in the existing Multiple equilibria supplement.
