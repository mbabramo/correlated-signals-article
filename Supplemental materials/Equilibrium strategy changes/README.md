# Equilibrium strategy changes

These are separate counterfactual best-response calculations using selected saved equilibria. They are not regenerated by the ordinary `diagrams results` command.

- `Calculations/Original`: full original fee/risk contrasts and saved coalition responses, reach, tie/completion checks and residuals.
- `Calculations/Mixed`, `Calculations/Mixed tighter check`, `Calculations/Mixing`: equilibrium-preserving mixing searches and recalculated comparisons.
- `Published source tables`: four focused tables and Methodology, with their source selection and validation records.
- `Fee trigger comparison`: Trial-to-Complete Fee-Shifting calculations under RN/RA at ordinary and high costs. They include initial nonanswer and later unilateral exit jointly.
- `selected-strategy-mechanisms.pdf/png`: canonical source of main Table 3. Seven rows preserve the original fee contrast, direct answering, opponent-mediated filing, a sensitive filing row, and unchanged filing with offsetting contributions.
- `Sources/Profiles`: the exact original equilibrium/action-report inputs to the separate analyses. They must not be replaced with reserialized reports from the routine rebuild. `Sources/relocation.json` records their hashes and the path-only request migration.

Main Table 3 is assembled by `python scripts/assemble_manuscript_exhibits.py` from the saved focused source tables and fee-trigger JSON. The assembly checks the selected row/group identities, allocations and flags and records source hashes. The caption distinguishes the original three-representation checks from the narrower trigger diagnostics. It does not claim that those checks cover every Complete Fee-Shifting equilibrium.

For a full recalculation, run `dotnet run --project LitigCharts -c Release -- equilibrium-changes --request "<request file>"` in ACESim4. Use the live `.request.json`, not `.recorded-request.json`. `--render-only` validates saved request/input/calculation hashes before rendering; `--calculate-only` performs calculations without rendering. The original focused selection and mixing workflows retain their own request and manifest records.

Direct-first accounting changes the primitive with the old opponent fixed, then averages opponent-entry/offer/exit contributions over six replacement orders. Residuals, ties and off-path completion sensitivity remain part of the evidence. These are explanations under a stated counterfactual convention, not identified causal shares, observed adjustment paths, or a decomposition of aggregate welfare.
